# Marca

`setup.png` é o card de As Lanternas dos Esquecidos RPG na tela de setup do Foundry
(`media` tipo `setup` no manifesto). A identidade usa lanternas e montanhas ilustradas
em SVG, as fontes do projeto (OFL) e o selo da Licença da Comunidade. Para refazer, o
HTML está em `scripts/marca/setup.html`; renderize a 1200×675 com o navegador headless
(`node scripts/marca/gerar.mjs`).
